# 故事线（假设实验结果理想）

按优势叙事的六条来写。叙事顺序是最终成立的逻辑，不是我们做事的时间顺序。

---

## 一句话主张

**思维链不必写成 token。在扩散语言模型里，它可以压成一小段连续的计划，在回答之前先解出来。**

拿到显式思维链的大部分质量收益，序列成本降一个量级，而且用多少思考是模型自己定的。

---

## 为什么只有扩散模型能讲这个故事

这是全篇的支点，必须在 intro 立住。

自回归模型里，思维链的成本是**结构性的**：推理必须先被写出来成为 token，后面的生成才能条件在它上面。想省掉这个成本，就等于不让模型看到自己的推理。

扩散模型没有这个约束，因为它有两件自回归拿不到的东西：

1. **序列的不同部分可以走不同的去噪时钟。** 「先想后写」可以是一个真实的调度事实，不是提示词里的一句话。计划槽在 t_plan 上先解完，回答在 t 上再解。
2. **产出的形状可以在产出之前定下来。** 包括「这道题要花多少思考」。自回归模型只能一个 token 一个 token 地发现自己要想多久，扩散模型可以一次性把预算定出来。

所以这不是「把某个 NLP 技巧搬到扩散模型上」，是**扩散模型独有的结构带来的一个新选项**。

---

## 摘要前三句（问题 → 缺口 → 解法）

> 思维链提升推理质量, 代价是序列长度. 自回归模型无法回避这个代价: 推理必须先成为 token, 才能被条件在上面. 我们把推理放进一个独立的计划流, 它在回答之前先被去噪解出, 并且长度由模型自己生成.

（硬规则：简单句，只用逗号句号问号冒号，intro 不报数字。）

---

## 战场：只打这三场

| 对手 | 口径 | 我们赢什么 |
|---|---|---|
| 同规模同数据、不给推理过程 | 准确率 | **赢质量** |
| 同规模同数据、把推理写成 token | 序列长度 / NFE / 墙钟 | **赢成本**，质量接近 |
| 消融（对角线 / 寄存槽 / 关掉计划） | 准确率 | **赢**，证明是「有序」和「内容」 |

**不打的比赛**：不和大模型比绝对分数，不进任何排行榜。绝对分数不进主线，只在实验节出现一次作为规模说明。

---

## 五个实验，各司其职

一个实验只当一个论点的主证据。

| # | 实验 | 唯一职责 |
|---|---|---|
| 1 | 质量-成本曲线：无推理 / 我们 / 显式推理 三条线 | 证明核心方法有效 |
| 2 | 四组消融：ordered / diagonal / register / vanilla | 说明优势从何而来，排除「只是多了参数」 |
| 3 | 思考预算：生成的预算 vs 题目难度；人为改预算 vs 质量 | 说明优势从何而来，且这是自回归拿不到的 |
| 4 | 内容审计：真计划 vs 同长度打乱的计划 | 排除「只吃了计划的粗状态」这个替代解释 |
| 5 | 成本表：序列长度、NFE、墙钟、峰值显存 | 在目标场景展示价值 |

理想结果长这样：

1. 我们在成本轴上比显式推理左移一个量级，质量轴上落在无推理和显式推理之间，且显著高于无推理。
2. ordered > diagonal > register ≈ vanilla。差的只有时钟和监督，参数完全一样。
3. 预算随难度单调上升。把预算压到一半，难题掉得比易题多。
4. 真计划显著优于同长度打乱的计划。
5. 序列长度 8×，墙钟 3× 以上的差距。

**注意第 3 条是全篇最独特的一张图**，它同时是机制证据和卖点。第 4 条是最容易被审稿人问的地方，必须自己先做掉。

---

## 成果逻辑（叙事顺序）

```
思维链有用, 但代价是序列长度
   ↓
自回归无法回避, 扩散可以: 不同部分可以走不同时钟
   ↓
我们把推理放进一个先解出来的计划流
   ↓
计划是压缩的, 所以必须证明剩下的够用
   ↓
够用 (实验 1)
   ↓
起作用的是「有序」和「内容」, 不是参数量 (实验 2, 4)
   ↓
预算是学出来的, 随难度变化 (实验 3)
   ↓
成本降一个量级 (实验 5)
```

不出现「我们先试了 A 失败了，然后改 B」。所有走过的弯路以消融或对照的身份出现，或者不出现。

## 数据要什么（故事线决定数据，不是反过来）

主张里有三个量必须能测，数据必须同时满足：

1. **准确率**，不是 ROUGE → 答案要可验证、唯一
2. **难度**，可控或可标注 → 否则实验 3 只能做相关性，做不成控制实验
3. **推理过程** → 需要成对的 (题目, 推理, 答案) 三元组

### 主战场：可控难度的合成推理任务

难度是自变量（推理步数），答案唯一，推理过程按构造生成。好处：

- 实验 3 从「相关性」升级成**控制实验**，这是全篇最强的一张图
- 干净，单一来源，license 无风险
- 规模随便造，可以按需要平衡难度分布
- 105M 学得会，不会撞地板

### 真实任务：GSM8K

证明不是只在合成任务上成立。它的 `answer` 字段天然就是「推理过程 + `#### N`」，拆开就是我们要的三元组，MIT license，1319 条标准 test，本地已有。训练量不够就配 orca-math 这类同格式的数据补。

### 明确不要什么

- 不要多来源混合。现在这个包 70.8% Nemotron + 16% dolphin-r1 + 13% GeneralThoughtArchive，三家格式、长度、题型都不一样。
- 不要 license 不明的。dolphin-r1 上游记的是 `unknown`，GeneralThoughtArchive 里混了 CC-BY-NC-SA。
- 不要选择题占大头。现在的可验证子集 54% 是选择题，瞎猜就有 20-25%，而模型实测 1-4%，指标实际在测「格式对不对」不是「答得对不对」。
- 不要没有难度标注的。没有难度就没有实验 3。

## 这个故事最脆的地方

内部讨论用，不进稿子。

**如果压缩后的计划带不动答案，实验 1 就不成立，整条线塌。** 我们已经测出：当前的 64×128 只保住结构，丢掉数字，答案保留率 37.5%，而同预算的 PCA 上限是 44%。

所以在按这条故事线大规模投入之前，先做一个**门槛实验**：在新数据上做容量阶梯，测「答案保留率 → 准确率」曲线。

- 曲线在某个容量之后起飞 → 按这条故事线全速做，容量选在拐点右边
- 曲线一路平 → 说明压缩的推理过程在可验证任务上带不动答案，那就换主张：把战场从「推理」移到「结构」，任务换成摘要，主指标 ROUGE 就变成合理的而不是代理的

这个判断只需要一条曲线，代价是几个 VAE 加几次 Stage-B，比先训一堆再发现塌了便宜得多。
